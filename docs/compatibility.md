# 兼容范围

最新平台结果请见[安装指南的实测表](installation.md#支持环境)。

| 层 | 支持与证据 | 边界 |
|---|---|---|
| 宿主 | 各系统的安装与启动结果见上方实测表 | 不自动豁免其他 DSH 版本 |
| 数据目录 | 本机 Linux 文件系统、单机同 PID 命名空间 | 跨机器共享盘、多命名空间并发不支持 |
| 浏览器 | 现代 Chromium；使用宿主 slots / conversation / settings 接口 | 真机 USB 本轮未测，手机尺寸测试不等于真机 |
| 窗口 | 普通模式四边四角缩放；展开模式只左右缩放 | 小于最小尺寸的屏幕优先不越出视口，正文滚动 |
| 模型 | 宿主模型适配层，合成适配器验证协议 | 不承诺所有第三方模型都输出合法结果 |
| 旧数据 | API v4、0.2.2/0.2.3 JSON 延续 | 丢失的最新内容不能凭旧备份重造 |

原生 Windows Node 的目录 fsync 探针返回 EPERM；不能通过略去同步步骤宣布支持。Windows 浏览器连接 WSL 宿主不受此限制。macOS 原生 rc.2 已通过安装、启动与登录后的插件响应检查。

浏览器优先使用支持原生 Popover 的版本。缺少 showPopover 或调用失败时有 fixed 定位回退，但无法保证绕开所有宿主变换祖先的裁剪/层叠；不是完整的 top-layer 模拟器。

运行时不依赖新 MCP 或第三方网络服务；官方 SDK 通过宿主的插件装配共享，不打入第二份模型或权限服务。构建依赖只用于开发。安装包包含必要产物与离线诊断工具。

安装器可能对SDK peer发出提示；不能把提示等同于运行失败，也不能以忽略/可选peer掩盖失败。验收需记录实际安装树、SDK解析路径、完整web启动、状态/API、浏览器与正常停机。尚未支持的宿主/平台不因测试夹具通过而扩大声明。

客户端静态模块依赖还包括 `@deepseek-ai/dsh-client-ui-primitives`（isBehindModal）。由 rc.2 Web 前端 seed 提供，构建保持 external；不额外安装宿主 UI 副本，不能把该工具模块盲目作为插件 inject。自定义 seed 缺失时不宣称支持。

## 0.4.8 数据边界

操作限制、当前所选指导和正文覆盖是三个独立事实。供匹配的排版投影不改写原稿，不提供权限；引用/代码/资料不能通过跨边界拼接被认作新要求。有限动作检查返回已体现、部分匹配或未知；没有匹配不是确认缺失。

suggest模型目录采用固定列的紧凑行，保留真实通用正文及适用限制。suggest结果的increment包含sourceBlockId/sourceQuote/snippetQuote，分别绑定本次真实原文与可信补句；字段齐全不等于语义获证。模型卡默认显示/选择通用正文，已有确认的技能文本不静默降级；方法库的技能写法继续由原有可用性校验负责。

已表达的勾选仍经过可信目录和原限制校验，作为核对指导保留；改写不应反复追加同一句。覆盖判断不替代原意与安全审校。AI协议8拒绝旧页面；个人库、调用账本与存储协议4不迁移。没有新增后台模型阶段或历史记忆库。
