# 使用 Prelude

[返回首页](../README.md)

## 先选一条适合自己的路径

| 情况 | 怎么做 | 是否调用模型 |
| --- | --- | --- |
| 已经知道想补什么 | 方法库搜索 → 预览补句 → 插入光标处或复制 | 否 |
| 不确定需求是否说清楚 | 分析提示词 → 查看建议及理由 | 是 |
| 想把要求整理为完整一段 | 按需选方法 → 改写整稿 → 对比候选 | 是 |
| 经常重复使用同一句要求 | 在“我的补句”保存，下次直接使用 | 否 |

## 分析与方法选择

打开 Prelude 后，默认只使用当前草稿。需要参考资料时，先预览上文或可读取的文本附件，再主动选取。

方法卡用专业术语作标题，同时提供用途解释、阶段、领域和补句。可按阶段、领域、收藏筛选；搜索覆盖卡片文字，空格分隔的多个词需要全部匹配。

“用于本次改写”仅选择方法，不立即修改输入框。最多同时选择八项，不必选满。“插入光标处”直接插入所见补句，与整稿改写是两种操作。

本地相关方法只是候选，不表示草稿有错。已经体现的方法可用于核对，不应该为了展示效果强行重复补写。

## 改写、审校与采用

点击“改写整稿”后，原输入框保持不变。查看原稿与候选，按需展开文字差异或编辑说明，也可以手动修改候选。

“生成后自动审校”默认关闭；开启时可能增加一次模型检查。审校失败或发现问题会明确提示，不会冒称通过。可以保留原稿、复制候选，或按可用操作修稿再审校。

确认后点击“采用到输入框”，回到输入框核对，最后由你发送。只有宿主状态仍允许时才可撤回本次替换；采用后继续编辑，快捷撤回不会覆盖新内容。

## 改了草稿或换了需求

草稿或依据改变后，旧候选会标为过期，不能继续当成新草稿的结果。点击“换个需求，重新开始”清理本次工作，再分析当前输入。它不会删除 DSH 输入、附件、个人库或模型设置；存在需要保留的手改内容时，先复制。

## 个人补句与设置

会话里的“我的补句”用于搜索、使用、新建和编辑。设置里的“个人库维护”用于导入、导出、回收恢复和永久移除。

个人库已保存项目与回收区合计最多 200 条。移入回收区仍可恢复；永久移除需要明确确认。导入先预览，容量不足时不会部分写入。

设置集中管理共用默认：模型、自动审校、显示偏好和个人库维护。九项默认展开包括补充要求、参考资料、常用搭配、模型设置、推荐卡正文、已体现方法、补充要求预览、文字差异和编辑说明。保存后在下次真正关闭并打开面板时应用，不强行打断本次手动开合。

## 面板布局

普通模式可拖动、四边和四角缩放；展开模式只左右移动与缩放。小屏以视口为界，内容滚动。宿主设置等弹窗打开时，Prelude 会让位；关闭后继续本次工作。
