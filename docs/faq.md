# 常见问题

[返回首页](../README.md)

### 为什么推荐了方法，改写却没加入？

推荐和采用不同。需要进入整稿的内容，先选择“用于本次改写”。即使选中，原稿已经体现的方法也可以只作为核对依据。

### 为什么没有建议，或候选与原稿相同？

需求可能已经清楚，也可能缺乏足够依据。Prelude 不为了展示变化强行增加要求。没有建议不是对提示词质量的最终认证。

### 为什么审校通过后再次分析，仍有建议？

审校主要检查原意和选定要求，分析寻找可能的补充，二者目的不同。有限规则与模型仍可能重复推荐；判断是否有实际帮助即可，不必反复优化。

### 为什么不能采用？

查看面板里的具体原因：可能是原稿已改变、候选违反要求、审校未完成、超出长度，或宿主命令/引用无法安全写回。可以保留原稿、修稿后重查，或复制文本手工处理。

### 是否只能用 DeepSeek？

不是。可以选择 DSH 已配置并能调用的模型。具体表现取决于模型和宿主适配器，不承诺所有供应商均有相同效果。

### 方法卡会替我执行测试或部署吗？

不会。方法卡提供提示词写法。插入“回归验证”不代表真的跑过测试；是否执行任务由你发送后的 DSH 会话决定。

### 能处理任意长文和附件吗？

不能。整稿原文上限 4,000 字符、候选上限 6,000 字符。资料需要可读取且在界面允许的容量内，不会静默截断或假装读过不支持的附件。

### 关闭面板会清空输入吗？

关闭面板不等于发送或删除草稿。“换个需求，重新开始”用于清理本次分析与候选，保留 DSH 输入、附件及长期设置；未保存内容请按界面提示处理。
