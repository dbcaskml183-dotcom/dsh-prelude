# 存储、停写和恢复

状态根为 `${DSH_HOME:-$HOME/.dsh}/prompt-coach`，不随插件卸载删除。个人库位于 `library/library-v2.json`，保存带修订号 CAS；`bak1/bak2` 是有限代际备份，不是灾备。两者可能比丢失的最新主库旧，恢复界面会显示条数。

## 主库缺失或损坏

1. 首次安装、没有主库也没有任何历史痕迹时允许创建。0.2.4 在首次发布主库前先保存恢复副本。
2. 有备份、坏备份或隔离痕迹而主库缺失时显示 `missing-protected`，拒绝普通保存，保留现有文件字节。
3. 有效备份可由用户明确选择恢复；恢复前再次核对 SHA。选哪代就恢复哪代，不能把较旧两条写成已经找回较新三条。
4. 没有有效备份时停止，先检查外部备份/权限/磁盘，不提供偷偷重置空库的按钮。
5. 旧版本第一次写入没有生成备份，且主库与所有历史文件都消失时，程序无法区分从未使用过的目录；需要外部备份，不能承诺任意文件删除都能恢复。

## 旧锁与诊断

在已解包的发行目录运行：

```sh
node bin/storage-doctor.mjs /absolute/path/to/prompt-coach
```

默认只读，不输出个人库正文/草稿/密钥。明确停用所有共享写入者之后，才考虑：

```sh
node bin/storage-doctor.mjs /absolute/path/to/prompt-coach --recover-proven-locks
```

后者是**写操作**，只在系统互斥下恢复可以证明归属的标记，不改 JSON。空锁、坏 JSON、活跃 PID、未知归属不会按年龄强抢。遇到未知旧锁：正常停用全部写入者，备份整个状态目录，核对拥有者、目录与进程来源；仍不能证明安全时保留现场求助。此处不提供基于“够老了”的删除命令或强制清锁按钮。

写入互斥由 Node SQLite 与兼容旧版文件屏障共同承担；目录 fsync 失败、权限错误或特殊文件不会被当作空库。不要让 0.2.2 与新版同时写同一状态目录。

## 生命周期与费用

禁用/卸载清除订阅、入口、样式和会话桶，取消客户端仍持有的请求及响应体解析；清理相互隔离。取消等待不能撤销已被后端接受的保存，也不代表供应商不计费。记账失败时保留结果并阻止进一步付费细化，诊断重试仅补记账，不再调用模型。

外部备份、磁盘故障恢复和长期留存属于用户维护范围，有限代际文件不能代替独立备份。

## 0.4.4 展开偏好升级与回退

九项默认展开偏好保存在本插件的宿主配置中，不写个人库。0.4.16新增五项，缺字段时内存回落为收起，不批量写盘迁移。回退前核对目标版本 schema 是否接受新增字段；不接受时先保留新值记录，再仅恢复与旧包匹配的 Prelude 配置字段，不能整份回写旧 profile 覆盖后来其他组件的更改。模型与审校配置保持既有含义。个人库格式不变，回退程序不能用旧数据覆盖期间新保存的内容。

## 0.4.7 不能安全读取的原件

当原件超出1MiB读取边界、是跳转链接/目录或存在权限/I/O问题时，状态会明确标注页面不能安全恢复/导出。有效备份仍列出，但不可行的恢复按钮被禁用；后端直接请求也拒绝。普通尺寸坏JSON、受保护的缺失主文件仍支持既有恢复。

离线处理：先正常停用所有共享该状态目录的写入者，保全整个 prompt-coach 状态目录（含坏原件、bak1/bak2和协调文件），确认目录归属、文件类型、磁盘与读取权限。核对所选备份的完整SHA与内容范围；需要人工替换时先将坏原件移到保全目录，保留旧备份和代际关系，再在停写状态恢复选定副本，重启后只读核对。不要在服务运行中替换文件，不跟随不明链接，不删除原件来强行重建空库；无法确认归属或介质故障时保留现场求助。

取消只结束等待，不保证供应商停止计费；本地关闭Promise仍未完成时 busy 保持真实。关闭失败会保留可用候选并停止该请求中的自动后续模型阶段，不自动重试。


## 个人库操作入口

会话的“我的补句”保留搜索、使用、新建、编辑和移入回收区。设置 → Prelude → 个人库维护集中导入导出、旧库迁移、回收恢复和永久移除。两处共用同一份数据与未保存编辑状态；关闭页面仍不会自动保存编辑。

未确认的导入预览在关闭设置后可以放弃，重新选择文件即可；已经提交的写入不因关闭界面撤销。结果未确认时重新打开并刷新核对，不自动重复提交。故障恢复保留原有独立条件，不将损坏库当成空库。
