# 选卡与设置的定向浏览器回归

`tools/browser-regression.mjs` 是真实页面事件的可执行断言，供已授权的 CUA 浏览器会话导入。它不建立浏览器、伪造模型返回、发送聊天或读取页面外数据；不计入 `npm test` 的离线测试数量。

1. 在自己的合成草稿上用真实模型完成“分析提示词”，应得到方法卡；再完成一次整稿改写，停留在候选对比页，不采用、不发送。
2. 导入模块，调用 `selectionRegression(tab, '当前可见的一张方法名称')`。它真实点击选卡，断言分析卡片保留、选中状态正确、不进入重新分析、旧候选不能继续采用，并出现重新生成入口。测试后这份旧候选保持过期，不能把它当成恢复前的可用结果。
3. 打开设置中的前奏，调用 `settingsRegression(tab)`。它切换“补充要求”的默认展开值，核对保存完成提示和实际勾选值，再恢复原值。重新打开设置，核对恢复结果仍在。
4. 记录调用结果、当前正式版本、实际浏览器状态和截图。发生断言失败立即保存现场，不点击发送。使用者的其他草稿与个人库不在测试范围内。

这是一组有明确前置条件的定向回归，不宣称自动覆盖任意宿主页面、所有浏览器或所有模型。
