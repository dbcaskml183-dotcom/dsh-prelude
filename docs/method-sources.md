# 方法与规范来源

[返回首页](../README.md)

方法库采用“专业术语 + 通俗解释 + 可使用的补句”，不是把网上的系统提示词原样打包。来源不等于授权背书，某项方法也不保证在所有模型上有效。

- [methods.json](../methods.json)：方法、阶段、领域与写法。
- [sources.json](../sources.json)：逐项来源与阅读范围。
- [guidance/rules.json](../guidance/rules.json)：用于生成的精简规范与来源。

规范只按任务选取少量相关内容，不在每次调用中塞入整份知识库。卡片表达的是任务要求，不代表后台自动执行了搜索、测试、多代理协作或训练。

新增内容应优先依据作者原文、官方文档或论文；保留出处，检查适用条件，避免未经验证的效果数字及厂商背书。
