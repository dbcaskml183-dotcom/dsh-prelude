# 整稿改写：可逆的编辑候选

## 操作

1. 照常填写DSH草稿，在前奏“当前建议”点击改写整稿。沿用既有跟随会话或固定模型，不改变主会话选模。
2. 原稿保持原样，生成候选只展示在面板；原稿框只读、候选框可编辑。宽窗并排，窄窗上下；文字差异可展开，不依赖颜色区分增删。
3. 核对后点击采用到输入框，使用宿主revision范围替换，不自动发送。候选采用后只读；继续改动请直接编辑DSH输入框。
4. 未继续编辑时可撤回本次替换；采用后有任何编辑或附件变化，快捷撤回不再覆盖，原稿仍可查看/复制。即使删回相同文字，revision变化也不重新获得旧事务权限。

候选缺少受保护原文或新增已识别高影响操作时不能采用，也不能确认绕过。模型结果同样经此校验。语义审校可选且默认关闭；手改使旧审校失效，有问题/失败的结果不会被切换开关洗成通过。你可对手改稿主动审校，或在硬检查通过后自行采用；这不意味着模型已替你验证。采用只是编辑当前草稿，不代表已发送或执行任务。

## 边界

- 4000字符原稿、6000字符候选；长稿不截断，选段不能冒充整稿。
- @引用与命令具有宿主语义，暂只预览/复制；附件ID另由宿主管理，采用前后须保持一致。
- 生成时改原稿、换会话或改变依据，旧候选不可覆盖新输入。
- 发送/切会话/卸载/取消可能令采用/撤回不可用，不自动重新应用候选。
- 快照只留在本页会话缓存，收起对比/卸载/缓存淘汰会释放；刷新不保证保留。不建永久提示词历史。
- 预算/权限/代码/网址等检查是有限防线，不能证明任意语言的语义100%无损。模型说明与未知项可能有误，不能代替原稿对比与用户判断。
- AI使用POST /api/prompt-coach/v8/suggest、/rewrite和/review；status、个人库与账本恢复仍为v4。旧AI POST返回409。新客户端须匹配analysisProtocol、rulesHash和review capability，不能猜测旧后端能力。

## 实现边界

shared/rewrite-contract负责有限协议和保护片段；host/service保留唯一模型执行/租约/账本管线；client/rewrite-controller只拥有会话内生成与编辑事务；shared/text-diff做有界纯文本比较；src/rewrite-view只负责展示。没有另造模型供应商、权限、会话或存储系统。

## 费用与取消

默认关闭自动审校；changed候选开启后增加一次审校阶段。手动“审校当前稿”是明确的独立调用，不会采用草稿。未选方法且原样候选不追加审校；已选方法时仍按本次自动审校选择核对方法。目标不明先本地询问，不编造ZIP内容。自动审校失败保留候选和失败状态，不能直接绕过采用。取消不能保证供应商停止收费，客户端丢弃迟到结果；底层仍收尾时租约继续阻止并发。当前期限见下方0.3.5条款：每阶段45秒、整体95秒。

## 0.3.1 文本保护与采用边界

- “候选与原稿相同，未运行额外审校”只表示没有文本变化，不表示原稿最优或已经审校。未明确选择的方法仍独立可选；0.4.0的“用于本次改写”会把用户确认的正文加入本轮依据。
- 本地目标澄清不发起生成或审校；开启自动审校也不改变这点。
- 生成、手改、主动审校和最终采用共用同一原文合同检查。权限反向、已识别的新授权、控制字符不能靠手改或开关绕过。模型审校不代替该检查。
- 候选以命令形式开头，或含歧义宿主引用时只预览/复制，禁止直接采用；普通邮箱、多段绝对路径、普通字面代码示例不按宿主命令处理；但真实 dsh-session: URI 在代码块/网址中仍会被 rc.2 解析，因此也只预览/复制。单段 /word 无法确认是路径还是命令时保守只预览。采用仅改草稿，不执行命令、不发送消息。
- 明确禁止/预算/输出合同按较小原文分句保护；描述“检查是否存在不允许发布的问题”不再因关键词锁住整段。保护是有限规则，不是任意语言和任意语义的证明；原意、范围与格式仍需用户对照。
- 本轮规则目录变更使 rulesHash 改变；旧页面请求会要求刷新，不把旧前端当新版验收。

## 0.3.2 补充边界

- 常见请勿/切勿/勿/别/不能/不可、只使用、用中文、输出：JSON等要求按原文小分句保留；冒号不再拆散键和值。正面授权不能删除、反转或重复增写。新增明确输出格式/语言同样拒绝；普通Markdown排版不是新增输出格式命令。
- 描述性问题、引用例句仍是数据，不能仅因出现“不允许”或“JSON”锁住普通文字。有限词法检查依旧可能保守或漏掉新语义；不能宣称任意自然语言都已覆盖。
- 按宿主rc.2实际URI解析规则拒绝直接写入 dsh-session: URI，无论是否有@、标点、行内代码或围栏；检查不读取任何被引用会话。个人补句和搭配插入共用该输入检查，仍可复制。普通补句可插入已有合法引用的草稿，不改动引用本身。
- 用户主动挑选的方法卡可以增加要求；整稿模型改写不能擅自增加要求。这两种操作不共用原文合同差异检查，但共用宿主输入语义检查。
- /tmp 等单段斜杠文本仍保守只预览/复制；已知多段路径不按命令处理。本版没有为消除该提示放宽命令保护。

## 0.3.3 要求识别

沿用 shared/prompt-contract.mjs 作为生成、服务端审校和前端采用的共同检查入口；条件关联句与实际源片段在这里识别，不增加独立解析服务或执行状态机。礼貌前缀只用于判断，受保护文本仍来自真实原文；必须/只/不得等操作符不剥离。描述性检查与源稿定向反转检查互为对照。有限词法检查不等同于语义证明；主 Agent 的权限与工具完全不变。

## 0.3.5 原意保真与修稿

生成先做安全结构解析，再做有限要求检查。安全但违反要求的候选可以预览，标为代码拦截；不能采用，也不会为已知代码问题额外调用审校。敏感/超长/无效结构不会成为预览。用户可手改，或明确点击按意见修正并审校；一次点击最多修稿与审校两个阶段，没有自动循环或自动采用。意见与旧候选不提供新授权。修稿失败/取消保留旧候选与旧问题。成功结果绑定旧候选，原稿/附件/会话版本变化后不能覆盖新编辑。

有限等价只改变同一指令头的说法，原对象、条件和硬字面量仍需保留；不必、避免、禁止、可以、建议与必须分别处理。任意语义等价与复杂指代不在代码证明范围内；辅助模型审校也不是正确性认证。

每个模型阶段最多45秒，最多两个阶段，总请求95秒、浏览器105秒；等待上限不是供应商生成token上限。产品不再额外传maxTokens；供应商或宿主自有上限仍有效。OUTPUT_LIMIT会明确说明输出被截断；第二阶段失败保留第一阶段候选，仍阻止自动采用。

用户明确点击的生成→审校/修稿在上次调用已收尾后可立即进入下一阶段；相同操作仍有两秒防连点，未收尾租约仍拒绝并发，不自动排队或延后计费。

## 0.4.0 诊断与方法选择

分析一次返回简短判断与最多3项建议，依据不足与调用失败分开。shared/method-selection为唯一纯要求组装器；手写context不被改写，临时选择只留本会话。显式选择正文经原explicitRequirements进入生成/代码检查/审校，没有新增权限或存储系统。冲突/超限显示并保留内容；方法文本不能替代缺失任务目标。指纹包含选择，旧候选失效；采用后方法从待用区收口，撤回恢复快照但不额外写草稿。AI协议6及规则哈希成对握手，旧v5不能执行；个人库与账本仍v4。

有限适用性与原意检查仍可能保守或漏判复杂自然语言。可以不改原稿；文字变化、预期帮助与任务效果不混同，不宣称每次提升或跨模型最佳。


## 0.4.1修订
selectedMethods传递目录确认快照；explicitRequirements只包含手写内容。方法允许自然改述，精确字面量和明确安全限制继续保护；代码仅检查有限副作用冲突。普通方法的完整语义覆盖依赖用户核对及可选模型审校，不保证任意语义等价。AI v7，存储v4。上述0.4.0实现描述保留作历史。


## 草稿变化与重新开始（0.4.3）
修改输入后，当前本地建议跟随草稿；上一份改写标为过期并折叠，仍可复制，不能直接采用或审校。手改候选但原稿未变，仍可继续编辑和明确重审。
继续同题会保留所选方法、补充要求和资料，并展示实际参与的依据。彻底换题可点固定可见的“换个需求，重新开始”：保留输入框和宿主附件，清理当前任务工作，不自动调用模型。
有用户手改、补充要求、手改未采用的资料预览或有效快捷撤回时，先确认放弃；取消不会提前停止原请求。重置之后旧结果不会回填，但已发出的模型调用可能仍计费。
新功能不提供重置撤销或历史版本库；关闭重开时同一输入所有者的工作保留，宿主切换会话若重建输入所有者，临时工作可能不恢复，不能把旧授权重新绑定来绕过这个边界。

## 0.4.8 数据边界

操作限制、当前所选指导和正文覆盖是三个独立事实。供匹配的排版投影不改写原稿，不提供权限；引用/代码/资料不能通过跨边界拼接被认作新要求。有限动作检查返回已体现、部分匹配或未知；没有匹配不是确认缺失。

suggest模型目录采用固定列的紧凑行，保留真实通用正文及适用限制。suggest结果的increment包含sourceBlockId/sourceQuote/snippetQuote，分别绑定本次真实原文与可信补句；字段齐全不等于语义获证。模型卡默认显示/选择通用正文，已有确认的技能文本不静默降级；方法库的技能写法继续由原有可用性校验负责。

已表达的勾选仍经过可信目录和原限制校验，作为核对指导保留；改写不应反复追加同一句。覆盖判断不替代原意与安全审校。AI协议8拒绝旧页面；个人库、调用账本与存储协议4不迁移。没有新增后台模型阶段或历史记忆库。


## 0.4.16 操作补齐

方法库选好卡后，“查看已选方法（N）”只返回已选区；之后仍由用户点击改写。选择上限八项，已有选择可以取消和替换。有效选段时所有整稿再生成入口一致不可用，取消后仍需检查完整草稿长度。

文字差异、编辑说明可设默认展开；当前结果审校、修稿或采用时不重置手动开合。过期和已撤回对比继续独立收起，仅供查看或复制。默认展开不代表新增模型调用，不改变采用与撤回条件。
